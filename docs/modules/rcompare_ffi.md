# Module: rcompare_ffi

Canonical doc: **[rcompare_ffi/README.md](../../rcompare_ffi/README.md)** (342
lines — building, C API reference, CMake integration, examples). Not duplicated
here to avoid drift between two copies of the same content.

One-line summary: C-compatible FFI over the patch engine in `rcompare_core`
(see [docs/modules/rcompare_core.md](rcompare_core.md#other-engines)) —
libkomparediff2-compatible, opaque-handle pattern, for C/C++/KDE consumers.
Parse/apply/unapply/blend/serialize diffs; does not expose comparison,
VFS, or GUI functionality — patch manipulation only.
